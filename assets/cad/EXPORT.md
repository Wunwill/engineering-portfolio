## Opening the Sample

Download the `.step` file and import it into CAD software that supports STEP AP242. It contains exported geometry rather than the original Onshape sketches, feature history, or editable assembly mates. It is a review sample, not a complete manufacturing release or a validated bill of materials.

The preview was generated locally from this exact file using Open CASCADE for surface tessellation and Matplotlib for rendering. Colors are neutral presentation colors, not original materials. The preview process does not modify the STEP file and is not a structural analysis.
